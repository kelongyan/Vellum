Vellum portable mode

While this file sits next to vellum.exe, Vellum keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the VellumData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Vellum with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Vellum and
%LOCALAPPDATA%\Vellum) instead. If VellumData can't be written (for example on a read-only
drive), Vellum says so and uses the per-user folders instead.
